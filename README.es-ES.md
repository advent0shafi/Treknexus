

# Sitio Web de Comercio Electrónico TrekNexus

¡Bienvenido a TrekNexus, tu destino definitivo para herramientas y equipo de actividades al aire libre! 🌄

TrekNexus es un sitio web de comercio electrónico construido con Python Django para la magia del lado del servidor, con PostgreSQL asegurando un almacenamiento de datos robusto y seguro. Esta plataforma te ofrece una experiencia de compra fluida combinada con funciones avanzadas para mejorar tu viaje de compras en línea.

## Características Principales

- **Verificación de Usuario**: ¡Priorizamos la seguridad! TrekNexus emplea verificación de usuario basada en OTP y verificación por correo electrónico para garantizar que tu experiencia de compra sea segura y agradable.

- **Pago Integrado**: Completa tus compras sin problemas con el pago integrado utilizando Razorpay, una pasarela de pago confiable y eficiente.

- **Despliegue en AWS**: TrekNexus se despliega con orgullo en AWS EC2 para una escalabilidad y confiabilidad inigualables. Utilizamos NGINX y Unicorn para garantizar un rendimiento óptimo y una experiencia de usuario fluida.

## Tecnologías Utilizadas

TrekNexus utiliza una potente combinación de tecnologías para brindarte una experiencia de comercio electrónico de primer nivel:

- **Python Django**: La fuerza impulsora detrás de TrekNexus, proporcionando un marco de trabajo robusto y dinámico del lado del servidor.

- **PostgreSQL**: Nuestra elección para el almacenamiento de datos, asegurando la gestión segura y eficiente de tu información valiosa.

- **Razorpay**: Integración de pago sin problemas para transacciones rápidas y sin complicaciones.

- **Ajax**: Mejora la interactividad y la capacidad de respuesta para una experiencia de usuario más fluida.

- **Unicorn**: Un servidor HTTP de alto rendimiento para el despliegue, que contribuye a la velocidad y confiabilidad del sitio web.

- **Bootstrap**: Garantiza un diseño elegante y responsivo que se adapta perfectamente a diferentes tamaños de pantalla.

- **Nginx**: Impulsa nuestro despliegue con NGINX para optimizar el rendimiento y manejar el tráfico entrante de manera eficiente.

- **AWS**: Alojado en AWS EC2, TrekNexus aprovecha el poder de la computación en la nube para una mayor escalabilidad y disponibilidad.

## Funciones de Comercio Electrónico

TrekNexus es más que un sitio web: es una experiencia. Estas son algunas de las características destacadas:

- **Búsqueda de Productos**: Encuentra tu equipo de exteriores rápidamente y de manera fácil con nuestra intuitiva funcionalidad de búsqueda de productos.

- **Carrito y Monedero**: Mantén un registro de tus compras y administra tu monedero sin problemas dentro de la plataforma.

- **Ofertas de Referidos**: Recomienda amigos y desbloquea ofertas y descuentos especiales.

- **Lista de Deseos**: Crea y administra tu lista de deseos para futuras compras.

- **Finalización y Pago**: Completa tu compra sin esfuerzo con nuestro proceso de pago simplificado.

- **Cupones y Ofertas**: Disfruta de ahorros adicionales con cupones y ofertas especiales de productos.

- **Corte y Zoom de Imágenes**: Acércate y observa con detalle nuestros productos utilizando el corte y el zoom de imágenes.

- **Informes de Ventas y Panel de Administración**: Los vendedores pueden rastrear las ventas utilizando informes completos y una representación gráfica en el panel de administración.

## Cómo Empezar

Sigue estos pasos para clonar y explorar el proyecto TrekNexus:

1. Abre tu terminal o símbolo del sistema.
2. Navega a tu directorio deseado usando el comando `cd`.
3. Ejecuta el siguiente comando para clonar el repositorio:
```sh
git clone https://github.com/advent0shafi/Treknexus.git
```

4. Una vez clonado, navega al directorio del proyecto:
 ```sh
cd Treknexus
```
5. Instala las dependencias necesarias ejecutando:
 ```sh
pip install -r requirements.txt
```
